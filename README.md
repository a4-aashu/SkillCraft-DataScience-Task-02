# 📊 SkillCraft Technology - Data Science Internship

## 📌 Task 02: Data Cleaning & Exploratory Data Analysis (EDA)

## 🎯 Objective

Perform data cleaning and exploratory data analysis on the Titanic Dataset to understand patterns, relationships, and insights from the data.

---

## 📂 Dataset

Titanic Dataset from Kaggle

---

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 🔍 Exploratory Data Analysis

Steps performed:

- Imported dataset
- Checked missing values
- Cleaned unnecessary data
- Analyzed passenger survival patterns
- Explored relationships between variables

---

## 📈 Key Insights

- Passenger class affected survival chances.
- Female passengers had higher survival rates.
- Age and fare showed important patterns.
- Data visualization helped identify trends.

---

## 📚 Key Learnings

- Data preprocessing techniques
- Handling missing values
- Understanding datasets
- Finding insights using visualization
